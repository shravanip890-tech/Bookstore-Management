📚 Book Store Management System

A web-based Book Store Management System developed using PHP, MySQL, HTML, CSS, and Bootstrap. This project aims to simplify bookstore operations and provide users with a convenient online book-shopping experience.

✨ Features

- 📖 Browse available books
- 👤 User registration and login
- 🛒 Shopping cart functionality
- 🧑‍💻 Customer profile management
- 📦 Order management
- 💳 Payment integration
- ⚙️ Administrative features

🛠️ Technologies Used

- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP

🚀 Installation and Setup

1. Install XAMPP on your computer.

2. Copy the project folder into the "htdocs" directory.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Open phpMyAdmin and create a database for the project.

5. Import the provided "database.sql" file, if included.

6. Update the database connection settings in the project configuration.

7. Open your browser and visit:
   
   "http://localhost/your-project-folder/"

🔐 Security Notes

- Use test credentials during development.
- Do not upload real passwords, private API keys, or payment secrets.
- Review database and payment configuration before publishing.

🎯 Project Objective

The objective of this project is to demonstrate the development of a database-driven bookstore website using PHP and MySQL. It provides practical experience with web development, database connectivity, user authentication, and e-commerce functionality.
